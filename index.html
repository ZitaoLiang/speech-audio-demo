Audio samples from “GRAINTTS: LESS CONTEXT, MORE DETAIL FOR COMPACT SPEECH SYNTHESIS”

Abstract: Compact acoustic models face a pronounced quality–capacity trade-off. We address two bottlenecks: encoder context allocation and Mel-spectrogram supervision. A fixed-receptive-field encoder improves acoustic-feature prediction, while local gradient-variance loss preserves fine-grained Mel details. GrainTTS contains only 264.8K parameters and achieves a UTMOS score of 4.09.

All model outputs below use the same HiFi-GAN v2 vocoder. Each row contains the same five held-out LJSpeech texts.
